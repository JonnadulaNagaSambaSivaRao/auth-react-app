# 🔐 React + FastAPI JWT Authentication System

A full-stack **User Registration and Login application** built using **React.js** for the frontend and **Python FastAPI** for the backend.

This project implements a secure authentication flow with:

- User Registration
- User Login
- JWT Token Authentication
- Password Hashing
- Protected Dashboard
- Frontend Form Validation
- Loading States
- Success/Error Messages
- Reusable React Components
- Responsive UI
- SQLite Database
- SQLAlchemy ORM
- FastAPI Swagger Documentation

---



The application now supports:

```text
Registration
     ↓
FastAPI Backend
     ↓
SQLite Database
     ↓
Login
     ↓

     ↓
Protected Dashboard
